# GhostCursor v0.3.0

将指定应用窗口共享到浏览器，显示访客鼠标或触摸位置，并由主持人明确授予、撤销鼠标控制。

## 本次更新

- Windows x64 安装版与便携版；新增 macOS 13+ Intel、Apple Silicon 的 DMG 与 ZIP。
- 新增 Swift / AppKit / CoreGraphics 原生组件，实现 Mac 窗口枚举、透明位置标记与经授权的鼠标操作。录屏和辅助功能权限均由 macOS 管理；前台丢失、遮挡、断线及撤销时停止输入并恢复指针。
- WebSocket 视频转发适合 FRP 单 TCP 端口；普通 WebRTC 可自动获取并探测 STUN；固定 UDP 模式使用 TCP 网页端口加 UDP 媒体端口。
- 分辨率、画质、帧率、按键录制快捷键与鼠标样式设置；Windows 10 图形兼容模式。
- GitHub Actions 分平台构建，在全部安装包生成成功后发布，附 SHA256 校验值。

## 下载选择

- Windows：`windows-x64-nsis.exe` 为安装版，`windows-x64-portable.exe` 为便携版。
- Mac Intel：`macos-x64.dmg` / `.zip`；Apple Silicon：`macos-arm64.dmg` / `.zip`。
- `SHA256SUMS.txt` 用于校验下载文件完整性。

## macOS 首次使用与验证范围

将应用移入「应用程序」，在「系统设置 → 隐私与安全性」允许 GhostCursor 录制屏幕和使用辅助功能。录屏权限变更后可能需要退出并重新打开应用。安装包采用 ad-hoc 签名，尚未使用 Apple Developer ID 签名及公证，系统可能要求在「隐私与安全性」中明确允许打开。

macOS 原生组件为首次发布，编译成功不代表真实设备链路通过；录屏授权、实际窗口捕获、辅助功能授权、悬浮层排除、全屏、多显示器和 Retina 缩放仍需 Mac 实机验收。Windows 的本次实际运行截图展示本机共享观看流程，不代表公网或跨设备验收。遵照此前要求，本次不执行自动测试套件。

固定 UDP 模式目前同时仅支持一位访客、IPv4 映射，必须真正转发 UDP。公网 FRP / Lucky、STUN / TURN 需按部署文档配置，未承诺任意网络可达。
